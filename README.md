# مساعد EMIS — تطبيق أندرويد

تطبيق أندرويد يشغّل سكربت **«مساعد EMIS – تعبئة تلقائية» v7.6.3** كما هو، بدون Tampermonkey.

## كيف يعمل
- ثلاثة تبويبات: **الطلاب** (موقع الطلاب) و **Excel** و **EMIS**. يفتح التطبيق على EMIS بشكل الهاتف.
- **«إرسال إلى EMIS»**: زر في صفحة المنسق في موقع الطلاب (`data-action="send-to-emis"`). عند ضغطه يفحص
  التطبيق الطالب في EMIS (الصف، الشعبة، المكان، رقم البطاقة)، ثم يعرض تأكيداً بما سيُسجَّل، ثم يسجّله عبر
  خادم EMIS ويحدد «تمت المراجعة» في الموقع. علامة ⚠ على الزر تدل على نقص في الاستمارة.
- **سجل العمليات**: كل إرسال مع نتيجته، بحث وتصدير Excel.
- **المقارنة**: من هو في موقع الطلاب وليس في EMIS (بالاسم الرباعي)، وتحديد «تمت المراجعة» للموجودين.
- **Excel**: تعبئة أي نموذج مفتوح في EMIS من صف في ملف (عنوان العمود = اسم الحقل).
- **المدارس**: قواعد في الإعدادات (`src/settings.ts`): لكل مدرسة مكان ومدينة ثابتان أو «حسب الاستمارة».
- السكربت (`userscript/emis-helper.user.js`) يُحقن في الصفحتين، ودوال `GM_*` تعمل عبر `src/bridge.ts`.

## تعديل السكربت
عدّل `userscript/emis-helper.user.js` ثم شغّل:
```
npm run embed
```

## التحديث
- كل بناء على GitHub ينشر «إصداراً» عاماً فيه `emishelper.apk` و `version.json` و `emis-helper.user.js`.
- التطبيق يتحقق عند فتحه: إن وُجد APK أحدث يعرض «تحديث جديد» ويثبّته بضغطة (يبقى تسجيل الدخول).
- إن كان السكربت فقط أحدث، يُنزَّل ويُستخدم بدون إعادة تثبيت التطبيق.
- ملاحظات التحديث تُكتب في `release.json`. ارفع `scriptMinBuild` فقط إذا احتاج السكربت الجديد ميزة غير موجودة في نسخ التطبيق الأقدم.

## بناء ملف APK
من GitHub: **Actions → Build APK → Run workflow**، ثم نزّل `emishelper-apk` من صفحة التشغيل.

محلياً (يحتاج Android SDK و Java 17):
```
npm ci
npx expo prebuild -p android
cd android && ./gradlew assembleRelease
```

> المشروع السابق (المزامنة والتصدير) محفوظ كما هو في `emishelper-android-source-v3.zip`.
