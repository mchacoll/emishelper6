# مساعد EMIS — تطبيق أندرويد

تطبيق أندرويد يشغّل سكربت **«مساعد EMIS – تعبئة تلقائية» v7.6.1** كما هو، بدون Tampermonkey.

## كيف يعمل
- شاشتان: **موقع الطلاب** و **EMIS** (تبديل من الأعلى، أو عرضهما معاً).
- **لوحة تحكم** في الأسفل: بطاقة الطالب الحالي، حالة العمل، وأزرار «تعبئة في EMIS»، «ص2»، «إيقاف»،
  «تمت المراجعة ⏭»، «تخطي»، وسجل مباشر.
- يُحقن السكربت (`userscript/emis-helper.user.js`) كما هو في الصفحتين، وشريطه الأزرق مخفي افتراضياً
  (اللوحة تضغط أزراره). يمكن إظهاره من الإعدادات.
- دوال `GM_*` تعمل عبر جسر داخل التطبيق (`src/bridge.ts`) ينقل القيم بين الشاشتين ويحفظها.
- أثناء التعبئة لا يظهر الكيبورد (حتى لا تقفز القوائم المنسدلة)، ويعود طبيعياً عند لمسك للحقل.
- **الإضافة التلقائية** (معطّلة افتراضياً): كل 1/2/5/10 دقائق يحدّث التطبيق موقع الطلاب، ويفتح أول طالب
  ليس عليه «تمت المراجعة»، ويُدخله في EMIS ويحفظه، ثم يحدده «تمت المراجعة» وينتقل للتالي حتى لا يبقى أحد.
  تعمل والتطبيق مفتوح ومسجّل الدخول في EMIS (الشاشة تبقى مضاءة)، وتتوقف عند أي حقل ناقص أو «رقم البطاقة مستخدم»
  أو مهلة، ولا تُدخل نفس الطالب مرتين في الجلسة.
- الإعدادات: تعبئة الطالب التالي تلقائياً، التنقل التلقائي، وضع الكمبيوتر لـ EMIS، الروابط، نسخ/مشاركة السجل.

## تعديل السكربت
عدّل `userscript/emis-helper.user.js` ثم شغّل:
```
npm run embed
```

## بناء ملف APK
من GitHub: **Actions → Build APK → Run workflow**، ثم نزّل `emishelper-apk` من صفحة التشغيل.

محلياً (يحتاج Android SDK و Java 17):
```
npm ci
npx expo prebuild -p android
cd android && ./gradlew assembleRelease
```

> المشروع السابق (المزامنة والتصدير) محفوظ كما هو في `emishelper-android-source-v3.zip`.
